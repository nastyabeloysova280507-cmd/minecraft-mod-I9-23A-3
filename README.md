# Команда 3
Участники проекта: Настя Белоусова, Мира Маслова
Цель проекта: Создание учебного модификатора "Вилы" для игры Майнкрафт на Java с использованием командной разработки в Git.

Структура проекта.
- `src/main/java` — исходный код мода на Java. Содержит пакет `ru.college.i923a с классом точки входа `MinecraftMod923A3` (реализует интерфейс `ModInitializer`и выводит диагностическое сообщение «Проект загружен успешно») и пакет `mixin`.
- `src/main/resources` — ресурсы мода: `fabric.mod.json` (идентификатор проекта, точка входа, зависимости) и `minecraft-mod-i9-23a-3.mixins.json.

Объект разработки
- Тип: инструмент — вилы (pitchfork).
- Рабочее имя: `pitchfork`.
- Пространство имён: `minecraft-mod-i9-23a-3` (совпадает с mod_id из fabric.mod.json).
- Полный идентификатор: `minecraft-mod-i9-23a-3:pitchfork`.
- Назначение: инструмент для быстрого сбора урожая — на 50% ломает стог сена быстрее чем алмазная мотыга и увеличивает дроп семян при скашивании травы.
